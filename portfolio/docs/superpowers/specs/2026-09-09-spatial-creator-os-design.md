# lilzho Spatial Creator OS 增量改造设计

## 目标

在现有 React + Vite 作品集上增量改造，不删除网易云扫码、完整歌单、本地音乐、删歌、换壁纸、悬浮播放器和部署能力。首页变成精选入口，作品、个人档案与声音空间拥有可深链的独立页面。

## 信息架构

- `?view=home`：个人定位、精选作品、个人档案、声音空间四个入口。
- `?view=works`：可扩展的播放器式作品空间。
- `?view=project&id=content-ai`：AI 短视频脚本生成器详情。
- `?view=about`：教育、能力、现在与未来方向。
- `?view=player`：完整声音空间与网易云连接。

浏览器前进、返回与直接打开 URL 都保持可用。

## 视觉系统

全站共用深石墨、暖白、铜橙，加入低饱和酒红和深青作为分区色。玻璃只用于导航和可交互表面。首页使用暗色视频与低密度粒子；作品空间使用空间旋转卡片和 Flowing Menu；项目详情使用代码扫描与 Dither；关于页使用安静的文字揭示；声音空间使用流体光场、折射玻璃与唱片旋转。每种核心效果只承担一个页面角色，并尊重 reduced-motion。

## 音乐性能

新增短时音源缓存与负缓存；歌单接口返回推荐可播放首曲并预热其音源；前端优先渲染首批曲目、渐进显示长歌单，使用 `preload=auto` 和 buffering 状态。二维码成功后使用合并的账号启动接口减少往返。版权受限歌曲仍明确提示，不伪装为可播放。

## 素材

复用仓库内 `autumn.mp4`、`particles.mp4`、`silver-motion.mp4`、`crimson-motion.mp4` 与现有 poster。缺失的原始临时附件不重新猜测或伪造。

## 验证

Node 单元测试覆盖路由、作品数据、歌单分页/推荐首曲、音源缓存与播放状态；Vite 构建通过；1440×1000 和 390×844 截图检查；部署后测量歌单读取与音频首段响应。
